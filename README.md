# Cardápiofast Printer Client

Cliente desktop (Windows/Linux) que o lojista instala no computador da loja para imprimir automaticamente os pedidos que chegam em tempo real.

Baixe o instalador mais recente em [Releases](https://github.com/ericstacks/cardapiofast-printer-client/releases/latest).
